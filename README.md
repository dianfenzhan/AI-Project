# SEO RAG Platform

基于 Java + Python 的 SEO 内容生成平台，实现 RAG 知识库、双路召回、AI 工作流等功能。

## 技术栈

### 后端
- Java 17 + Spring Boot 3.5
- Python 3.x + FastAPI + LangChain + LangGraph
- PostgreSQL（租户管理）
- Milvus（向量存储）
- Elasticsearch（全文检索）
- Docker Compose（服务编排）

### 前端
- Vue 3 + Element Plus + Vite

### AI
- DeepSeek / 通义千问 / 豆包（可切换）
- Sentence-Transformers（向量化）
- FlashRank（重排序）
- SerpAPI（Google 搜索）

## 快速开始

### 启动顺序

建议按下面顺序启动：先启动数据库和检索组件，再启动 Python RAG/DAG 服务，然后启动 Java 网关，最后启动 Vue 前端。

#### 1. 启动基础服务（PostgreSQL + Milvus + Elasticsearch + Kibana）

```bash
docker compose up -d
```

#### 1.1 初始化 PostgreSQL 租户表（Java 启动前必须执行）

Java 端 JPA 配置为 `ddl-auto: validate`，**必须先建表再启动 Java**，否则会启动失败。

连接信息（与 `docker-compose.yml` / `application.yml` 一致）：

| 项 | 值 |
|----|-----|
| Host | `localhost:5432` |
| Database | `example_db` |
| User | `admin` |
| Password | `password` |

**执行初始化脚本**（建表 + 插入 5 个租户，脚本见 `sql/tenant_init.sql`）：

```bash
docker exec -i postgres psql -U admin -d example_db < sql/tenant_init.sql
```

或使用本机 `psql`：

```bash
psql "postgresql://admin:password@localhost:5432/example_db" -f sql/tenant_init.sql
```

验证：

```sql
SELECT id, tenant_id, name, collection_name, default_llm_provider FROM tenants ORDER BY id;
```

**表结构 DDL**：

```sql
CREATE TABLE IF NOT EXISTS tenants (
    id                   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tenant_id            VARCHAR(255) NOT NULL UNIQUE,
    name                 VARCHAR(255) NOT NULL,
    collection_name      VARCHAR(255) NOT NULL,
    default_llm_provider VARCHAR(20)  DEFAULT 'deepseek',
    created_at           TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at           TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

**预置 5 个租户**：

| tenant_id | name | collection_name | default_llm_provider |
|-----------|------|-----------------|----------------------|
| tenant_001 | Acme SaaS | acme_kb | deepseek |
| tenant_002 | Globex E-commerce | globex_kb | qianwen |
| tenant_003 | Initech Fintech | initech_kb | doubao |
| tenant_004 | Umbrella Health | umbrella_kb | deepseek |
| tenant_005 | Stark Manufacturing | stark_kb | qianwen |

上传/搜索/生成时，`tenantId` 填上表中的 `tenant_id`，`collectionName` 填对应的 `collection_name`（或统一用 `default` 也可，但演示租户隔离建议用表中值）。

更完整的说明见根目录 [`多租户与文档权限说明.md`](多租户与文档权限说明.md)。

#### 2. 安装 Python 依赖

需要 **Python 3.11+**（推荐 Homebrew 安装：`brew install python@3.11`）。在 `python/` 目录下创建虚拟环境并安装依赖：

```bash
cd /path/to/Project-Self/python
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

首次安装会下载 `sentence-transformers`、`flashrank` 等较大依赖（含 PyTorch），可能需要几分钟。

若提示 `No module named pip`，先执行 `python3 -m ensurepip --upgrade`；若仍失败，可重装 Python：`brew reinstall python@3.11`。

#### 3. 启动 Python API 服务

必须在 `python/` 目录下启动（代码使用 `from RAG import ...` 相对导入）：

```bash
cd /path/to/Project-Self/python
source .venv/bin/activate   # 新终端需要先激活虚拟环境
python3 api_server.py
```

#### 4. 启动 Java 后端

新开一个终端：

```bash
cd java
mvn spring-boot:run
```

#### 5. 启动前端

新开一个终端：

```bash
cd frontend
npm install
npm run dev
```

### 推荐验证流程

启动完成后，建议按下面流程验证阶段一功能：

1. 打开前端 UI: `http://localhost:5173/seo-frontend/`
2. 进入「文档上传」页面，填写 `tenantId` 和 `collectionName`，上传 PDF / MD / TXT / DOCX 文档
3. 进入「知识库搜索」页面，用同一个 `tenantId` 和 `collectionName` 搜索刚上传文档中的内容
4. 进入「文章生成」页面，填写主题、关键词、租户 ID、集合名称，选择 AI 模型
5. 点击「第一步：生成标题」，从 5 个标题中选择一个
6. 点击「第二步：生成大纲」，从 3 套大纲中选择一套
7. 点击「第三步：生成文章」，检查文章是否基于知识库和 SerpAPI 搜索结果生成

### 停止服务

停止 Docker 基础服务：

```bash
docker compose down
```

Python API、Java 后端、前端开发服务在各自终端按 `Ctrl+C` 停止。

## 功能说明

### 1. 文档上传与索引
- 支持 PDF、MD、TXT、DOCX 格式
- 语义切块（512 token，128 overlap）
- 向量化存储到 Milvus
- 全文索引到 Elasticsearch
- **文档范围**：系统级（全员共享）/ 租户级（仅本租户），见上传页「文档范围」
- 租户隔离 + 系统级共享库

### 2. 双路召回与重排序
- 向量检索（Milvus）
- 全文检索（Elasticsearch）
- Query 改写 + 多查询召回，提升召回覆盖率
- FlashRank 重排序
- Top 10 结果返回

### 3. SerpAPI 搜索
- Google 搜索相关内容
- 自动抓取网页内容
- 集成到 RAG 上下文

### 4. SEO 文章生成 DAG
- 基于 RAG + SerpAPI 生成 5 个标题
- 选择标题后生成 3 套大纲
- 根据选定大纲生成完整文章
- 可切换 AI 模型（DeepSeek / 通义千问 / 豆包）
- 使用 LangGraph 中断恢复（human-in-the-loop）实现三步交互

### 5. RAG 质量与溯源
- 文章生成后返回 `quality_report`，评估忠实度、相关性、结构性和引用覆盖率
- 返回 `citations`，可追溯到知识库 chunk 或网页搜索结果
- 前端生成页展示 query 改写结果、质量评分、风险建议和引用来源

## API 接口

### Java 后端 (`/seo-java`)
- `POST /seo-java/api/v1/upload` - 上传文档（支持 `scope=tenant|system`）
- `POST /seo-java/api/v1/search` - 搜索知识库
- `POST /seo-java/api/v1/generate/titles` - 第一步：生成 5 个标题
- `POST /seo-java/api/v1/generate/outlines` - 第二步：基于选中标题生成 3 套大纲
- `POST /seo-java/api/v1/generate/article` - 第三步：基于选中大纲生成文章
- `POST /seo-java/api/v1/tenants` - 创建租户

### Python 后端 (`/seo-python`)
- `POST /seo-python/api/upload` - 文档处理与索引
- `POST /seo-python/api/search` - 双路召回搜索
- `POST /seo-python/api/generate/titles` - 第一阶段生成标题（返回 thread_id）
- `POST /seo-python/api/generate/outlines` - 第二阶段生成大纲（需传 thread_id + selected_title）
- `POST /seo-python/api/generate/article` - 第三阶段生成文章，并返回质量评估和引用来源（需传 thread_id + selected_outline）

### 前端 (`/seo-frontend`)
- `/seo-frontend/` - 单页工作台（Tab：租户文档上传 / 系统文档上传 / 知识库搜索 / 文章生成）
- `/seo-frontend/?tab=tenant-upload|system-upload|search|generate` - 直达指定模块

## 配置说明

API 密钥已配置在代码中，可通过环境变量覆盖：
- `DEEPSEEK_API_KEY`
- `QIANWEN_API_KEY`
- `DOUBAO_API_KEY`
- `SERP_API_KEY`
- `DOUBAO_MODEL`（建议配置为方舟推理接入点 ID，例如 `ep-xxxxxx`）

RAG 检索（**中英文双语**，见 `python/RAG/config.py`）：

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `EMBEDDING_MODEL` | `text-embedding-v4` | 通义多语言向量（DashScope API） |
| `EMBEDDING_DIM` | `1024` | 须与模型一致 |
| `RERANK_MODEL` | `ms-marco-MultiBERT-L-12` | 多语言重排 |
| `INDEX_PROFILE` | `v4` | Milvus/ES 集合名后缀 |

> Embedding API Key 默认复用 `DAG/config.py` 中的 `QIANWEN_API_KEY`；也可设置环境变量 `DASHSCOPE_API_KEY`。  
> **切换 embedding 或 `INDEX_PROFILE` 后，必须重新上传文档**（旧集合不兼容）。新数据写入 `{collection}_{tenant}_v4` 这类带后缀的索引。

## 注意事项

1. 所有服务的重启策略设置为 `no`，重启电脑后不会自动启动
2. 租户隔离通过 `tenant_id` 和 `collection_name` 实现
3. 首次启动会下载 FlashRank MultiBERT 等小模型；Embedding 走通义 API，无需本地下载 bge-m3
4. 依赖中 SerpAPI 对应包为 `google-search-results`
