#  项目介绍
为解决 SEO 领域内容同质化严重、逻辑性差及"AI 味"过重的问题，自主研发的基于 RAG 与多 Agent 协作的自动化内容生产平台。采用 Java (后端服务/任务调度) + Python (AI 核心逻辑) 的双栈协作架构，系统通过混合检索增强上下文，并利用多智能体协同完成从热点分析、大纲规划到长文撰写的全闭环，生成符合 Google SEO 标准的高质量文章。



# 个人职责：
作为技术负责人带领 5 人团队，从 0 到 1，设计、开发、最终交付项目。主要负责以下功能的开发和设计:

## RAG 混合检索架构设计：
针对单一检索的局限性，设计了 ES (关键词稀疏检索) + Milvus (向量稠密检索) 的双路召回机制，并引入 Re-rank (重排序) 策略筛选 Top 10 切片，显著提升了召回精准度。



## DAG 工作流编排：
一期基于 LangGraph 设计并实现了"分析-规划-执行-反思"的 Agentic Workflow。通过 DAG (有向无环图) 编排数据采集、根因分析、内容生成与人工审核四大节点，实现了高度自动化的 SEO 运营流程。

构建自动化决策机制，当监控到关键词排名下降时，Agent 自动触发竞品分析与文章优化任务，无需人工干预。



## 多 Agent 并发优化
二期基于 LangGraph实现多 Agent 并发优化文章。在一期的基础上实现节省时间。



## 上下文记忆与 Prompt 工程：
设计 "滑动窗口 + 长期摘要记忆" 机制，结合 边界感知 (Context-Aware) 的文档分块策略，解决了超长文章生成中的上下文丢失问题。

研发 动态思维链 (CoT) 提示词模板，通过三段式生成与角色扮演（Persona），并结合 Langfuse 进行链路监控与 Ragas 自动化评测，成功降低了内容的 Perplexity (困惑度)，有效规避 AI 检测。



## 模型路由与成本优化：
设计 Model Router 策略，针对不同复杂度的任务动态路由模型（如简单意图识别用 GPT-3.5，复杂推理用 GPT-4），结合 Redis 语义缓存，在保证质量的同时降低 Token 成本 40%。



# 项目业绩
实现了 SEO 文章的全自动流水线生产，相比传统人工方式，内容产出效率提升 5 倍以上。

通过混合检索、知识图谱增强以及多 Agentic Workflow，文章的 Google 收录率与自然搜索排名显著提升。

建立了基于 Langfuse 的全链路监控与 Ragas 自动化评测体系，实现了 Prompt 版本管理、成本追踪与效果评估的闭环，将知识库问答的准确率。
