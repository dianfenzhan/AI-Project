# 业务目标
- 构建 RAG 知识库，存储 SaaS 租户的产品文档，以及 SEO 的行业知识文档
- 基于主题和关键词，生成标题，再生成大纲，再生成文章
- 利用 AI Agent 自主优化文章，最终提高搜索排名，帮助客户营销产品
- 利用 LangFuse 开源工具，监控 AI，监控检索和生成。

# 整体技术栈
整体技术栈使用 Java+Python，涉及到 RAG 和 Agent 的地方使用 Python，基于 LangChain 和 LangGraph 写，涉及到工程化，对前端暴露 API 的，则用 SpringBoot 3.5.14,我本地有 JDK17
# 阶段一目标
- 构建一个 RAG知识库，可以上传 PDF，MD，Word 类型的文档
- 构建双路召回的系统，Milvus + ES，然后用行业的标准最终 reRank 出一个 top 10
- 使用 serpAPI, 搜索google文档，然后爬虫下来，也是 top 5给到 AI
- 然后 AI 生成标题，再生成大纲，再生成文章，每一步都是基于 RAG 到的数据，以及 serpAPI 搜索到的文档，生成标题的时候，可以生成 5 个让客户选择，生成大纲的时候，可以生成 3 套大纲，客户可以选择其中的一套，再生成文章的时候，会根据大纲，以及 RAG 到的数据，生成文章。生成文章的模版可以参考 /Document/模版/生成文章的模版.md
- 需要有一套 UI 界面，我需要用 Vue.js来写，因此帮我写一套 UI 界面，文档上传的时候，需要做好租户隔离，这样每个租户不会搜到别的公司的文档
- 这其实已经是一个小型的 DAG 工作流了，请帮忙用 LangChain 的 LangGraph 来实现这个工作流。

# 阶段二-目标
利用 DAG 优化 文章，最终提高搜索排名，帮助客户营销产品
比如，可以从Chrome console 获取文章排名，关键词的热度以及竞争程度，然后利用 AI Agent 自动优化文章
